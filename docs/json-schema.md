# JSON 出力スキーマ

`tree::to_json` / CLI `--json` の出力形式。`--lines --json` では
1行 = 1オブジェクトの JSONL としても出力できる。

## 形式

```json
{
  "version": 1,
  "rule": "text",
  "text": "mi klama do",
  "children": [
    { "rule": "content", "text": "...", "children": [ ... ] }
  ]
}
```

| フィールド | 型 | 内容 |
|---|---|---|
| `version` | number | スキーマ版数。**ルートオブジェクトのみ**に存在(v0.39 以降) |
| `rule` | string | pest 規則名(`{:?}` 形式。例: `KOhA_core`) |
| `text` | string | そのノードが覆う原文(部分文字列) |
| `start` / `end` | number | 元入力中のバイトオフセット(`[start, end)`。v0.72 以降) |
| `children` | array | 子ノード。葉ノードでは省略 |

## 規約

- `EOI`(入力終端マーカー)は出力から除外される
- `text` は親ノードの部分文字列であり、子ノードの `text` を連結したものと一致する
- ZOI 引用を含む入力では、解析木は正規化後テキスト(`zo'e` 置換)に基づく
- 消去語(si/su)を含む入力では、解析木は消去適用後のテキストに基づく
- ルートの `rule` は常に `"text"`

## 版数ポリシー

- フィールドの**追加**は版数を上げない(後方互換)。
  実績: v0.72 で `start`/`end` を追加(版数 1 のまま)
- フィールドの削除・意味変更・構造変更は版数を上げる
- 現在の版数: **1**(v0.39 で導入)
